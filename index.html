Konfigurasi Google Apps Script & Drive

Masukkan URL Web App dari Google Apps Script agar foto tersimpan otomatis ke Google Drive dan data tercatat ke Google Sheets.

Panduan Integrasi Google Drive & Sheets:

1. Buat Google Sheet baru dan siapkan folder di Google Drive untuk foto.

2. Salin kode Backend Apps Script (disediakan di bawah) ke editor script.

3. Masukkan ID Folder Google Drive pada variabel `FOLDER_ID` di script.

4. Deploy sebagai Web App (akses: Anyone) dan salin URL `/exec` di atas.
